# Source Ledger

Use this skill to keep evidence traceable across a long-running research task.

## Ledger Fields

Each source row should include:

- Source ID
- Title
- URL or stable locator
- Source type
- Retrieved date
- Claims supported
- Caveats
- Open questions

## Write Rules

- Do not cite a source in the brief unless it appears in the ledger.
- Do not merge several sources into one ID.
- Keep unsupported claims in open questions or notes.
- Record unavailable skills and failed calls as run events.

## Review Questions

1. Which claims depend on this source?
2. Is the source primary, secondary, or unknown?
3. Does the source support the wording used in the draft?
4. What should the next reviewer inspect?
