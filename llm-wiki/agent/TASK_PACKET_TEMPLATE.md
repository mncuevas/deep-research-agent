# Task Packet Template

## Task

Create a research brief for:

- Topic:
- Research question:
- Scope:
- Public sources only: yes/no
- AI-Q allowed: yes/no

## Required Outputs

- `wiki/research-briefs/<topic>.md`
- `raw/<topic>_source_ledger.md`
- `raw/<topic>_open_questions.md`
- `raw/<topic>_run_log.md`

## Forbidden Actions

- No claims without source IDs unless marked `needs_review`.
- No internal or private data unless explicitly allowed.
- No hidden skill failures or omitted unavailable backends.

## Review Criteria

- Every important claim has source provenance.
- Contradictions are preserved.
- Source weight is labeled.
- Open questions are clear.
