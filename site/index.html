LangChain Deep Agents framework

Deep Agents is LangChain's higher-level harness for tasks that need more than a single model call and a few tools. It gives the model a runtime with planning, filesystem state, subagents, skills, permissions, and a repeatable invocation path.

The useful way to read this repo is from the constructor outward. The model is the reasoning engine. Tools are deterministic Python callables. The backend gives the run a workspace. Permissions set read and write boundaries. Skills encode reusable procedures. Subagents isolate focused work.

from deepagents import create_deep_agent

agent = create_deep_agent(
    model=config.model,
    tools=[create_task_packet, record_source, classify_source, build_source_ledger, prepare_aiq_research_request],
    backend=_workspace_backend(config),
    permissions=_workspace_permissions(),
    skills=[str(config.skills_dir)],
    subagents=build_subagents(config),
    system_prompt=COORDINATOR_PROMPT,
)

1. Create the Deep Agent

The call to create_deep_agent binds together the model, tools, backend, permissions, skills, subagents, and coordinator prompt. Each argument should be explainable as a design decision.

2. Add skills and subagents

Skills describe procedures the agent can follow. Subagents split source collection, synthesis, AI-Q routing, and read-only review into focused workers.

SkillPurpose
research-scoutCollect source-backed material.
source-ledgerPreserve source IDs and caveats.
wiki-curatorStage durable LLM Wiki artifacts.
aiq-researchPrepare optional NVIDIA AI-Q research requests.

3. Run and review

The final answer is not the main deliverable. The staged brief, source ledger, open questions, and run log are what make the run reviewable.
